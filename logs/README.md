# Logs / Nhật ký hệ thống

## Purpose / Mục tiêu

Thư mục này chuẩn bị cấu trúc log cho application, security, error, audit và AI.

## Folders / Thư mục

- `application`: log hoạt động ứng dụng.
- `security`: log bảo mật.
- `error`: log lỗi.
- `audit`: log hành động quan trọng.
- `ai`: log tương tác AI đã ẩn dữ liệu nhạy cảm.

## Rule / Quy tắc

Không commit log thật. Log không được chứa password, token, API key hoặc dữ liệu cá nhân không cần thiết.
