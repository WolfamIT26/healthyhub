# Audit / Theo dõi hành động

## Purpose / Mục tiêu

Audit system dùng để theo dõi hoạt động người dùng, đề xuất AI, thay đổi quản trị và sự kiện bảo mật.

## Files / File

- `user-actions.md`: theo dõi hoạt động người dùng.
- `ai-actions.md`: theo dõi hành động và đề xuất AI.
- `security-events.md`: theo dõi sự kiện bảo mật.

## Rule / Quy tắc

Audit log thật không được commit vào Git nếu chứa dữ liệu người dùng hoặc thông tin nhạy cảm.
