# AI Actions / Hành động AI

## Scope / Phạm vi

Theo dõi đề xuất sản phẩm, phản hồi chat AI, meal plan, phân tích kinh doanh và các output AI có ảnh hưởng đến người dùng hoặc vận hành.

## Required Fields / Trường dữ liệu dự kiến

- Feature name.
- User hoặc admin liên quan nếu có.
- Input category, không lưu raw input nhạy cảm.
- Output status.
- Provider.
- Fallback status.
- Time.

## Safety / An toàn

Không lưu secret, prompt nhạy cảm hoặc dữ liệu cá nhân không cần thiết.
