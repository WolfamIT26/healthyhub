# User Actions / Hành động người dùng

## Scope / Phạm vi

Theo dõi các hành động quan trọng của người dùng như đăng nhập, cập nhật hồ sơ, đặt hàng, đánh giá sản phẩm và thay đổi thông tin giao hàng.

## Required Fields / Trường dữ liệu dự kiến

- User id.
- Action.
- Target.
- Time.
- IP hoặc device metadata nếu cần.
- Result.

## Privacy / Quyền riêng tư

Không lưu dữ liệu cá nhân vượt quá mục đích audit.
