# Security Events / Sự kiện bảo mật

## Scope / Phạm vi

Theo dõi đăng nhập thất bại, truy cập trái phép, thay đổi quyền, token bất thường, rate limit và sự kiện nghi ngờ tấn công.

## Severity / Mức độ

- Low: sự kiện cần theo dõi.
- Medium: sự kiện cần kiểm tra.
- High: sự kiện cần xử lý ngay.
- Critical: sự kiện cần phản ứng khẩn cấp.

## Response / Phản ứng

Mỗi sự kiện High hoặc Critical cần có report trong `security/reports`.
