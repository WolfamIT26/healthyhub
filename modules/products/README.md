# Product Module / Module sản phẩm

## Purpose / Mục tiêu

Product owns public catalog identity, pricing, visibility, content and relationships to Category/Brand/Media. Inventory remains the availability and quantity authority.

## Executable Scope / Phạm vi đã chạy

- Public Product list/detail/options APIs from MySQL.
- Server search/filter/sort/pagination and related Product selection.
- Admin Product list/detail/create/update/lifecycle/soft-delete from the same persistence.
- Admin Product Category/Brand/existing Media relationship management.
- Catalog, Product Detail and Search frontend server integration.
- Compatibility with ProductCommerceReader, Cart, Wishlist, Order snapshots and Review history.

Inventory quantity adjustment, Media upload infrastructure, import/export jobs, Review moderation, Promotion, Supplier and AI remain outside Prompt 35.
