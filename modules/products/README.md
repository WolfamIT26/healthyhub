# Product Module / Module sản phẩm

## Purpose / Mục tiêu

Product owns public catalog identity, pricing, visibility, content and relationships to Category/Brand/Media. Inventory remains the availability authority.

## Executable Scope / Phạm vi đã chạy

- Public Product list/detail/options APIs from MySQL.
- Server search/filter/sort/pagination and related Product selection.
- Catalog, Product Detail and Search frontend server integration.
- Compatibility with ProductCommerceReader, Cart and Wishlist.

Admin Product CRUD, upload, Inventory mutation, Review, Promotion, Supplier and AI remain outside Prompt 31.
