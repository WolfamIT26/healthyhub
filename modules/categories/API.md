# Category API / API Category

- `GET /api/v1/public/categories`: page/pageSize/q.
- `GET /api/v1/public/categories/tree`: complete public tree.
- `GET /api/v1/public/categories/{categoryId}`: numeric ID or slug.
- `GET /api/v1/admin/products/options`: Product-scoped Admin lookup returns active Category options for Product assignment.

Standalone Admin Category CRUD endpoints remain design contracts until a dedicated Category management prompt.
