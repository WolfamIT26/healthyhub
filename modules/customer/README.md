# Customer Module / Module khách hàng

Context pack cho Customer Profile và Address Book V1. Source of truth gồm CustomerProfile/UserAccount hiện hữu, `customer_addresses`, Customer self API, `/account/profile`, `/account/addresses` và Checkout prefill.

Owner luôn derive từ authenticated Customer. Module không triển khai Admin Customer Management, Change Email/Password, loyalty, payment methods hoặc AI advisor.
