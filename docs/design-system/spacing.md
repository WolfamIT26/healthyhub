# Spacing / Khoảng cách

## Purpose / Mục tiêu

Spacing tạo nhịp đọc ổn định giữa storefront, form checkout và admin dashboard. Quy tắc này chỉ định nghĩa khoảng cách thiết kế, không viết CSS.

## Spacing Scale / Thang khoảng cách

| Token / Token | Value / Giá trị | Usage / Cách dùng |
| --- | --- | --- |
| `space.0` | 0 | Không có khoảng cách. |
| `space.1` | 4 | Khoảng cách icon-label, field helper. |
| `space.2` | 8 | Khoảng cách nhỏ trong component. |
| `space.3` | 12 | Khoảng cách giữa label và control hoặc item nhỏ. |
| `space.4` | 16 | Khoảng cách mặc định giữa field, card content. |
| `space.5` | 20 | Khoảng cách nhóm nhỏ. |
| `space.6` | 24 | Khoảng cách section trong form/list. |
| `space.8` | 32 | Khoảng cách section trang. |
| `space.10` | 40 | Khoảng cách giữa block lớn. |
| `space.12` | 48 | Khoảng cách hero hoặc page section lớn. |

## Layout Spacing / Khoảng cách layout

- Storefront dùng spacing thoáng hơn để sản phẩm dễ xem.
- Checkout dùng spacing vừa phải, ưu tiên đọc từng bước.
- Admin dùng spacing chặt hơn nhưng không làm table khó đọc.
- Mobile giảm khoảng cách section nhưng giữ khoảng cách chạm an toàn cho button và input.

## Component Spacing / Khoảng cách component

- Button có padding đủ để dễ bấm trên mobile.
- Input và select phải có khoảng cách label, helper và error rõ.
- Table cell không quá rộng ở admin; dữ liệu cần dễ quét theo hàng.
- Product Card giữ khoảng cách rõ giữa ảnh, tên, giá, trạng thái và CTA.
