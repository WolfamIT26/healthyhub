# Footer / Chân trang

## Purpose / Mục đích

Footer cung cấp thông tin cửa hàng, chính sách, liên hệ, điều hướng phụ và tín hiệu tin cậy cho storefront.

## Variant / Biến thể

- Public Footer: thông tin mua hàng, chính sách, liên hệ.
- Minimal Footer: auth/checkout nếu cần giảm phân tâm.
- Admin Footer: thông tin hệ thống hoặc version nếu cần.

## Size / Kích thước

Standard cho storefront, compact cho auth/checkout/admin.

## State / Trạng thái

Default, loading settings, partial data, error fallback.

## Accessibility / Khả năng tiếp cận

Link phải có label rõ. Thông tin liên hệ không chỉ trình bày bằng icon.

## Responsive Rule / Quy tắc responsive

Mobile xếp các nhóm link thành một cột hoặc accordion nếu dài.

## Usage / Cách dùng

Dùng ở public pages, blog, product list/detail. Checkout có thể dùng footer tối giản.

## Do / Nên

- Hiển thị chính sách cần thiết.
- Giữ link SEO/public rõ.
- Dùng thông tin từ settings đã duyệt.

## Don't / Không nên

- Không đặt CTA cạnh tranh với checkout action.
- Không nhồi quá nhiều text pháp lý dài.
- Không dùng footer làm nơi chứa nội dung không liên quan.
