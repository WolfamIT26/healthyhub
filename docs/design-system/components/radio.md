# Radio / Nút chọn một

## Purpose / Mục đích

Radio dùng khi người dùng phải chọn đúng một lựa chọn trong nhóm nhỏ như phương thức thanh toán, phương thức giao hàng hoặc loại sắp xếp đơn giản.

## Variant / Biến thể

- Standard Group: danh sách lựa chọn đơn giản.
- Card Radio: lựa chọn có mô tả như payment/shipping method.
- Inline Radio: lựa chọn ngắn trong form.

## Size / Kích thước

Default cho form. Card radio có vùng bấm lớn hơn để phù hợp checkout.

## State / Trạng thái

Unchecked, checked, focus, disabled, invalid.

## Accessibility / Khả năng tiếp cận

Radio group phải có group label. Mỗi option cần label rõ và mô tả nếu ảnh hưởng phí/thời gian.

## Responsive Rule / Quy tắc responsive

Mobile ưu tiên radio card full-width cho lựa chọn checkout. Admin filter có thể dùng inline nếu ít option.

## Usage / Cách dùng

Dùng cho payment method, shipping method, customer type hoặc lựa chọn trạng thái đơn giản.

## Do / Nên

- Dùng khi option loại trừ nhau.
- Hiển thị mô tả tác động như phí giao hàng.
- Giữ option được chọn rõ.

## Don't / Không nên

- Không dùng radio cho danh sách dài.
- Không dùng radio khi người dùng có thể chọn nhiều option.
- Không đổi dữ liệu nhạy cảm ngay khi chọn nếu cần xác nhận.
