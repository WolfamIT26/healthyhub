# Tag / Thẻ phân loại

## Purpose / Mục đích

Tag dùng để biểu diễn nhóm thông tin như category, ingredient, dietary note, blog topic, campaign audience hoặc filter đã chọn.

## Variant / Biến thể

- Static Tag: chỉ hiển thị.
- Removable Tag: filter/tag có thể xóa.
- Selectable Tag: tag có thể chọn trong filter.
- Warning Tag: dị ứng hoặc lưu ý thành phần.

## Size / Kích thước

Small cho metadata, medium cho filter và product detail.

## State / Trạng thái

Default, selected, removable, disabled, warning.

## Accessibility / Khả năng tiếp cận

Tag có action xóa/chọn cần label rõ. Warning tag phải có text, không chỉ màu.

## Responsive Rule / Quy tắc responsive

Tag list trên mobile phải wrap gọn và không đẩy CTA chính quá xa.

## Usage / Cách dùng

Dùng cho ingredient, category chip, active filter, blog topic và AI source labels.

## Do / Nên

- Dùng tag cho thông tin ngắn.
- Giới hạn số tag hiển thị trên card.
- Dùng warning style cho dị ứng/lưu ý quan trọng.

## Don't / Không nên

- Không dùng tag thay button chính.
- Không nhồi quá nhiều tag trong product card.
- Không dùng tag màu giống status nếu ý nghĩa khác nhau.
