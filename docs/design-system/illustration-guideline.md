# Illustration Guideline / Quy tắc minh họa

## Purpose / Mục tiêu

Illustration dùng để hỗ trợ empty state, onboarding nhẹ hoặc nội dung blog. Đối với commerce, hình ảnh sản phẩm thật quan trọng hơn minh họa.

## Usage Rule / Quy tắc sử dụng

| Context / Ngữ cảnh | Rule / Quy tắc |
| --- | --- |
| Product | Ưu tiên ảnh sản phẩm thật, rõ, đủ sáng, không crop che thông tin quan trọng. |
| Empty State | Có thể dùng minh họa đơn giản nếu giúp người dùng hiểu bước tiếp theo. |
| Blog | Có thể dùng ảnh hoặc minh họa liên quan nội dung healthy, tránh hình chung chung. |
| Admin | Hạn chế minh họa; ưu tiên dữ liệu, bảng, trạng thái và hướng xử lý. |
| AI | Minh họa AI phải thể hiện hỗ trợ, không tạo cảm giác AI quyết định thay người. |

## Asset Rule / Quy tắc asset

- Asset dùng chung đặt trong `assets/illustrations`, `assets/images`, `assets/banners` hoặc `assets/logos`.
- Tên file asset dùng tiếng Anh và thể hiện nội dung.
- Không dùng ảnh tối, mờ, crop quá mạnh cho sản phẩm cần xem chi tiết.
- Không dùng hình minh họa tạo hiểu nhầm về lợi ích y tế của sản phẩm.
