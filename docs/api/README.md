# API Documentation / Tài liệu API

## Purpose / Mục tiêu

Thư mục này mở rộng `docs/05-api.md` để chứa Swagger, OpenAPI và liên kết API collections. API Specification thiết kế bằng Markdown nằm tại `.spec/api`.

## Mapping / Ánh xạ

- API Specification: `.spec/api`.
- OpenAPI specification chính thức: `openapi`.
- OpenAPI placeholder/tài liệu cũ: `docs/api/openapi`.
- Swagger guideline: `docs/api/swagger`.
- API collections: `api-collections`.
