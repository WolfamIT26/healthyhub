# Modules / Tài liệu module

## Purpose / Mục tiêu

Thư mục này chứa tài liệu cho từng module nghiệp vụ khi module được khởi tạo.

## Required Module Files / File bắt buộc cho mỗi module

Mỗi module phải sao chép cấu trúc từ `docs/modules/_template` hoặc `.ai/templates/module` và có đủ:

- `README.md`.
- `Requirement.md`.
- `Database.md`.
- `API.md`.
- `Frontend.md`.
- `Backend.md`.
- `Testing.md`.
- `Checklist.md`.
- `Prompt.md`.
- `Status.md`.
- `Report.md`.
- `ChangeLog.md`.
- `Decision.md`.
- `TODO.md`.

## Planned Modules / Module dự kiến

- `auth`: xác thực và phân quyền.
- `customer`: hồ sơ và trải nghiệm khách hàng.
- `product-catalog`: sản phẩm, danh mục, tìm kiếm và so sánh.
- `cart-order`: giỏ hàng và đơn hàng.
- `payment`: thanh toán và refund.
- `inventory`: tồn kho.
- `ai-platform`: AI Gateway và AI capability.
- `marketing`: chiến dịch, nội dung và email.
- `analytics`: phân tích bán hàng, tồn kho và khách hàng.
- `notification`: email, SMS và push notification.
