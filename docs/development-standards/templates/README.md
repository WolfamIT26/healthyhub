# Development Standards Templates / Mẫu chuẩn phát triển

## Purpose / Mục tiêu

Thư mục này chứa các mẫu Markdown để AI Agent và developer dùng khi triển khai module ở phase sau. Đây không phải code, không phải API, không phải migration và không phải UI implementation.

## Template List / Danh sách mẫu

- [Development Task Report Template](development-task-report-template.md).
- [Module Implementation Checklist Template](module-implementation-checklist-template.md).
- [Code Review Report Template](code-review-report-template.md).

## Usage Rule / Quy tắc sử dụng

- Sao chép cấu trúc mục, điền nội dung thật theo task/module.
- Không xóa mục test, security, performance hoặc documentation update.
- Nếu mục nào không áp dụng, ghi rõ "Không áp dụng" và lý do.
