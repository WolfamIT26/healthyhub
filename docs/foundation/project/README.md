# Project Documentation / Tài liệu dự án

## Purpose / Mục tiêu

Nhóm Project ghi lại lý do tồn tại, phạm vi, hướng phát triển và ngôn ngữ chung của HealthyHub. Đây là điểm bắt đầu trước khi đọc kiến trúc hoặc quy trình.

## Documents / Danh sách tài liệu

- [Project Overview / Tổng quan dự án](project-overview.md)
- [Vision / Tầm nhìn](vision.md)
- [Scope / Phạm vi](scope.md)
- [Roadmap / Lộ trình](roadmap.md)
- [Glossary / Thuật ngữ](glossary.md)

## Usage / Cách dùng

- Product Owner dùng nhóm này để giữ phạm vi dự án ổn định.
- Developer dùng nhóm này để hiểu mục tiêu trước khi thiết kế kỹ thuật.
- AI Agent dùng nhóm này làm ngữ cảnh chung trước khi phân tích requirement.
