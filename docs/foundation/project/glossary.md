# Glossary / Thuật ngữ

## Purpose / Mục tiêu

Glossary giúp developer và AI Agent dùng cùng một ngôn ngữ khi đọc tài liệu hoặc tạo đặc tả.

## Terms / Thuật ngữ

| Term / Thuật ngữ | Meaning / Ý nghĩa |
| --- | --- |
| AI Development OS | Bộ quy tắc, tài liệu, template và workflow giúp AI Agent phát triển dự án có kiểm soát. |
| Foundation Documentation | Bộ tài liệu nền quy định nguyên tắc chung trước khi tạo đặc tả tính năng hoặc code. |
| Modular Monolith | Kiến trúc một ứng dụng triển khai chung nhưng chia module rõ ràng theo nghiệp vụ. |
| Microservice-ready | Thiết kế module và dependency đủ sạch để có thể tách service trong tương lai. |
| Presentation Layer | Lớp giao tiếp với người dùng hoặc client bên ngoài. |
| Gateway Layer | Lớp bao bọc tích hợp bên ngoài như AI, payment, storage, notification. |
| Business Layer | Lớp xử lý quy tắc nghiệp vụ. |
| Data Layer | Lớp truy cập và lưu trữ dữ liệu. |
| AI Layer | Lớp năng lực AI dùng xuyên hệ thống. |
| Context Pack | Gói ngữ cảnh rút gọn theo module để AI đọc đúng thông tin và tiết kiệm token. |
| ADR | Architecture Decision Record, tài liệu ghi nhận quyết định kỹ thuật quan trọng. |
| Spec | Bộ đặc tả tính năng trong `.spec/features`, là nguồn để AI sinh tài liệu chi tiết hoặc code sau này. |
| Gateway Contract | Quy ước đầu vào, đầu ra, lỗi, timeout và logging của một gateway. |
| Audit Log | Dữ liệu ghi lại hành động quan trọng phục vụ truy vết và bảo mật. |

## Update Rule / Quy tắc cập nhật

Khi xuất hiện thuật ngữ lặp lại trong tài liệu hoặc prompt, cập nhật glossary trước để tránh mỗi agent hiểu một kiểu.
