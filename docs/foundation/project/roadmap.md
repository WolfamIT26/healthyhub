# Roadmap / Lộ trình

## Foundation Roadmap / Lộ trình nền tảng

Roadmap ở đây mô tả thứ tự trưởng thành của framework, không thay thế roadmap tính năng sản phẩm trong `planning/roadmap.md`.

## Phase 1 / Giai đoạn 1

Khởi tạo AI Development OS: tạo cấu trúc thư mục, tài liệu gốc, AI rules, AI skills, prompt templates, module templates, security/testing/deployment guideline nền tảng và workflow tổng quát.

## Phase 2 / Giai đoạn 2

Mở rộng framework: workspace management, assets, email/notification templates, i18n, OpenAPI collection, ERD folders, UI prototype folders, AI memory, AI personas, context packs, research, SEO, analytics, legal, release management và `.spec`.

## Phase 3 / Giai đoạn 3

Tạo Foundation Documentation: chuẩn hóa tài liệu dự án, kiến trúc, tiêu chuẩn, workflow, bảo mật, hiệu năng, testing, deployment, AI và ADR để làm nguồn tham chiếu chính.

## Next Phases / Các giai đoạn tiếp theo

- Khóa quyết định backend framework bằng ADR.
- Tạo đặc tả module đầu tiên trong `.spec/features`.
- Thiết kế database theo từng feature.
- Thiết kế API theo từng feature.
- Bắt đầu triển khai code có kiểm thử và cập nhật tài liệu.
