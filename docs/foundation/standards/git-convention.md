# Git Convention / Quy ước Git

## Purpose / Mục tiêu

Git Convention giúp lịch sử thay đổi dễ đọc, dễ review và dễ release. Mỗi thay đổi nên nhỏ, có mục tiêu rõ và đi kèm tài liệu bị ảnh hưởng.

## Working Rule / Quy tắc làm việc

- Không commit file secret hoặc dữ liệu nhạy cảm.
- Không gom nhiều mục tiêu không liên quan vào một commit.
- Không sửa format toàn repo nếu task không yêu cầu.
- Không xóa hoặc ghi đè thay đổi của người khác khi chưa có xác nhận.
- Mỗi PR phải nêu phạm vi, tài liệu đã cập nhật và cách kiểm tra.

## Review Rule / Quy tắc review

Reviewer ưu tiên tìm lỗi hành vi, rủi ro bảo mật, thiếu test, thiếu tài liệu và phá vỡ ranh giới module. Góp ý style chỉ nên chặn merge nếu ảnh hưởng maintainability hoặc chuẩn dự án.
