# ADR Guide / Hướng dẫn ADR

## Purpose / Mục tiêu

ADR ghi lại quyết định kỹ thuật có tác động dài hạn. ADR không cần dài, nhưng phải đủ rõ để người đọc hiểu bối cảnh, lựa chọn, lý do và hệ quả.

## When to Create ADR / Khi cần tạo ADR

Tạo ADR khi:

- Chọn backend framework chính thức.
- Chọn AI provider hoặc model policy.
- Chọn storage provider.
- Thay đổi kiến trúc module hoặc layer.
- Thay đổi chiến lược database lớn.
- Thay đổi security model.
- Thêm công nghệ mới ngoài stack đã khóa.

## ADR Content / Nội dung ADR

ADR phải có status, context, decision, options considered, consequences và follow-up. Nếu quyết định ảnh hưởng tài liệu khác, phải liên kết tới tài liệu cần cập nhật.
