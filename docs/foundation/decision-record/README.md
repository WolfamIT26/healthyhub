# Decision Record / Nhật ký quyết định

## Purpose / Mục tiêu

Decision Record lưu các quyết định kiến trúc quan trọng để team và AI Agent hiểu vì sao dự án chọn một hướng. ADR giúp tránh tranh luận lại cùng một vấn đề khi ngữ cảnh cũ đã mất.

- [ADR Template / Template ADR](adr-template.md)
- [ADR Lifecycle / Vòng đời ADR](adr-lifecycle.md)

## Existing ADR Location / Vị trí ADR hiện có

ADR chính của framework đang nằm tại `docs/architecture/adr`. Thư mục này cung cấp hướng dẫn foundation; khi tạo ADR thật, ưu tiên lưu vào `docs/architecture/adr`.
