# ADR Template / Template ADR

## Title / Tiêu đề

ADR-XXX: Tên quyết định kỹ thuật.

## Status / Trạng thái

Đề xuất, chấp nhận, thay thế hoặc hủy.

## Context / Bối cảnh

Ghi vấn đề cần quyết định, ràng buộc hiện tại, tài liệu liên quan và lý do không thể để mặc định.

## Decision / Quyết định

Ghi lựa chọn cuối cùng bằng câu rõ ràng. Nếu quyết định có phạm vi giới hạn, nêu rõ phạm vi.

## Options Considered / Lựa chọn đã cân nhắc

Ghi các phương án chính, ưu điểm, nhược điểm và lý do không chọn.

## Consequences / Hệ quả

Ghi tác động tích cực, rủi ro, chi phí vận hành, ảnh hưởng bảo mật, hiệu năng, testing và tài liệu.

## Follow-up / Việc cần theo dõi

Ghi các file cần cập nhật, checklist cần làm và thời điểm review lại quyết định nếu có.
