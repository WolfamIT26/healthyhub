# Manual Test Guideline / Hướng dẫn manual test

## Purpose / Mục tiêu

Manual test dùng cho những phần khó tự động hóa hoặc cần đánh giá trải nghiệm: UI tiếng Việt, luồng mua hàng, trạng thái lỗi, nội dung dinh dưỡng, output AI và tích hợp bên ngoài.

## Manual Test Checklist / Checklist kiểm thử tay

- Người dùng hiểu được màn hình bằng tiếng Việt.
- Loading, empty, error và success state rõ ràng.
- Không hiển thị dữ liệu sai quyền.
- Form validation dễ hiểu.
- Luồng quan trọng có thể hoàn thành trên desktop và mobile viewport.
- AI output có disclaimer hoặc kiểm soát phù hợp khi liên quan sức khỏe.

## Evidence Rule / Quy tắc bằng chứng

Manual test nên có ghi chú môi trường, tài khoản test, dữ liệu test, kết quả và screenshot khi liên quan UI.
