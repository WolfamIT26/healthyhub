# AI Documentation Guide / Hướng dẫn tài liệu AI

## Purpose / Mục tiêu

AI Documentation giúp lưu tri thức về prompt, context, skill, memory, review và quyết định AI ngay trong repository. Điều này làm giảm phụ thuộc vào trí nhớ của từng agent hoặc cuộc hội thoại riêng lẻ.

## Required AI Documentation / Tài liệu AI cần có

- AI rule cho hành vi bắt buộc.
- AI skill cho từng loại nhiệm vụ.
- Prompt chuẩn cho từng workflow.
- Context pack theo module.
- AI memory cho decision history, lessons learned và architecture history.
- AI review checklist cho output có rủi ro.

## Documentation Rule / Quy tắc ghi tài liệu

Mỗi AI feature sau này phải ghi rõ input, context source, prompt version, output format, safety rule, logging rule, fallback và test approach. Nếu feature dùng knowledge base nội bộ, phải nêu nguồn dữ liệu và cách cập nhật.
