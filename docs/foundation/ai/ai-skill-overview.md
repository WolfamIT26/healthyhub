# AI Skill Overview / Tổng quan AI skill

## Purpose / Mục tiêu

AI Skill là năng lực làm việc có hướng dẫn của AI Agent trong repository. Skill giúp agent biết phải đọc gì, tạo gì, kiểm tra gì và cập nhật tài liệu nào.

## Current Skill Groups / Nhóm skill hiện có

- Operating System skill cho quy trình chung.
- Requirement analysis skill.
- Architecture design skill.
- Database design skill.
- API design skill.
- Frontend design skill.
- Backend design skill.
- AI feature design skill.
- Testing and review skill.
- Documentation update skill.
- Release management skill.

## Skill Usage Rule / Quy tắc dùng skill

AI Agent phải chọn skill theo nhiệm vụ. Nếu nhiệm vụ chỉ là tài liệu, không dùng skill triển khai code. Nếu nhiệm vụ liên quan nhiều domain, agent phải đọc skill chính và context pack liên quan trước.
