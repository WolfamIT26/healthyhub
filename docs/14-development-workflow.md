# Development Workflow / Quy trình phát triển

## Flow / Luồng chuẩn

```text
Requirement
↓
Architecture
↓
Database Design
↓
API Design
↓
Frontend Design
↓
Backend Development
↓
Testing
↓
Review
↓
Documentation Update
↓
Release
```

## Step Rule / Quy tắc từng bước

- Requirement: xác định mục tiêu, scope, user flow và acceptance criteria.
- Architecture: xác định module, layer, gateway và dependency.
- Database Design: xác định table, relationship, index và migration.
- API Design: xác định endpoint, permission, request, response và error.
- Frontend Design: xác định screen, component, state và UX state.
- Backend Development: triển khai service, validation, repository và gateway.
- Testing: kiểm thử unit, integration, E2E và security khi cần.
- Review: kiểm tra bug, risk, performance và tài liệu.
- Documentation Update: cập nhật toàn bộ file bắt buộc.
- Release: cập nhật changelog và checklist release.
