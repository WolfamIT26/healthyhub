# ADR-002 Database Decision Template / Mẫu quyết định database

## Status / Trạng thái

`Proposed`

## Context / Bối cảnh

Mô tả nhu cầu thay đổi hoặc quyết định liên quan database.

Chưa quyết định.

## Notes / Ghi chú
