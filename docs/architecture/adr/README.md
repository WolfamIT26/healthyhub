# ADR / Architecture Decision Record

## Purpose / Mục tiêu

ADR ghi lại quyết định kiến trúc quan trọng, lý do chọn và hệ quả.

## Rule / Quy tắc

Khi thay đổi architecture, database strategy, AI provider, storage hoặc deployment pattern, phải tạo ADR hoặc cập nhật ADR liên quan.
