# ADR-003 AI Provider Decision Template / Mẫu quyết định AI provider

## Status / Trạng thái

`Proposed`

## Context / Bối cảnh

Mô tả nhu cầu chọn AI provider hoặc model.

## Decision / Quyết định

Chưa quyết định.

## Notes / Ghi chú

Cần đánh giá chất lượng output, chi phí, latency, privacy, fallback và lock-in.
