# User Journeys / Hành trình người dùng

## Guest Journey / Hành trình Guest

1. Truy cập website.
2. Xem danh mục hoặc tìm kiếm sản phẩm.
3. Đọc chi tiết sản phẩm, thành phần, hình ảnh và lưu ý.
4. Thêm sản phẩm vào giỏ hàng.
5. Đăng ký/đăng nhập hoặc tiếp tục đặt hàng theo chính sách.
6. Hoàn tất thông tin đặt hàng.

Điểm cần tối ưu: tìm sản phẩm nhanh, thông tin dễ hiểu, không bắt đăng nhập quá sớm nếu chưa cần.

## Customer Journey / Hành trình Customer

1. Đăng nhập tài khoản.
2. Xem sản phẩm, ưu đãi hoặc gợi ý.
3. Thêm sản phẩm vào giỏ.
4. Áp dụng coupon nếu có.
5. Đặt hàng và chọn phương thức thanh toán/giao hàng.
6. Theo dõi trạng thái đơn.
7. Nhận hàng, đánh giá sản phẩm và nhận chăm sóc sau mua.

Điểm cần tối ưu: lịch sử mua, gợi ý phù hợp, trạng thái đơn rõ ràng.

## Staff Journey / Hành trình Staff

1. Đăng nhập trang quản trị.
2. Xem danh sách đơn cần xử lý.
3. Kiểm tra thông tin khách, sản phẩm và tồn kho.
4. Cập nhật trạng thái đơn.
5. Phối hợp giao hàng hoặc chăm sóc khách.
6. Ghi chú vấn đề nếu đơn bị hủy hoặc cần hỗ trợ.

Điểm cần tối ưu: ít thao tác, tránh nhầm trạng thái, quyền vừa đủ.

## Admin Journey / Hành trình Admin

1. Đăng nhập với quyền quản trị.
2. Quản lý sản phẩm, danh mục, tồn kho và media.
3. Quản lý nhân sự, quyền và cấu hình cửa hàng.
4. Xem báo cáo kinh doanh và vận hành.
5. Thiết lập promotion, notification và nội dung.
6. Theo dõi audit log cho thay đổi quan trọng.

Điểm cần tối ưu: cấu hình an toàn, báo cáo rõ, phân quyền kiểm soát tốt.
