# Feature Map / Bản đồ tính năng

## Overview / Tổng quan

Feature Map liệt kê tính năng theo giai đoạn. Tài liệu này không mô tả API, database hoặc UI chi tiết.

## MVP Features / Tính năng MVP

- Xem danh sách sản phẩm.
- Xem chi tiết sản phẩm.
- Tìm kiếm sản phẩm cơ bản.
- Lọc theo danh mục.
- Giỏ hàng.
- Đặt hàng cơ bản.
- Quản lý trạng thái đơn hàng cơ bản.
- Quản lý sản phẩm.
- Quản lý danh mục.
- Quản lý hình ảnh sản phẩm.
- Quản lý tồn kho cơ bản.
- Quản lý người dùng quản trị.
- Cấu hình cửa hàng cơ bản.

## Version 1 Features / Tính năng Version 1

- Đăng ký và đăng nhập khách hàng hoàn chỉnh.
- Lịch sử đơn hàng khách hàng.
- Mã giảm giá.
- Chương trình khuyến mãi.
- Quản lý thanh toán ở mức trạng thái.
- Quản lý giao hàng.
- Đánh giá sản phẩm.
- Blog nội dung healthy.
- Notification cho đơn hàng và tài khoản.
- Dashboard quản lý cơ bản.
- SEO metadata cho trang sản phẩm và blog.

## Version 1.5 Features / Tính năng Version 1.5

- Loyalty điểm thưởng.
- VIP Customer.
- AI Chat hỗ trợ khách.
- AI Product Recommendation.
- AI Search.
- AI Product Compare.
- AI Marketing Assistant.
- AI Sales Analysis.
- AI Inventory Insight.
- Customer segmentation.
- Campaign performance tracking.

## Version 2 Features / Tính năng Version 2

- Mobile app preparation.
- Multi-store readiness.
- Role permission nâng cao.
- Advanced inventory planning.
- Subscription hoặc membership package.
- Advanced analytics dashboard.
- Integration với shipping/payment provider thật.
- AI Nutrition Planner có kiểm soát an toàn.

## Future Features / Tính năng tương lai

- SaaS tenant management.
- Supplier portal.
- Marketplace sản phẩm healthy.
- B2B wholesale.
- AI personalization sâu theo lịch sử mua và mục tiêu dinh dưỡng.
