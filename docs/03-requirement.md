# Requirement / Yêu cầu hệ thống

## Product Scope / Phạm vi sản phẩm

HealthyHub là nền tảng bán sản phẩm healthy:

- Sữa hạt.
- Sữa chua.
- Đồ ăn dinh dưỡng.
- Thực phẩm sức khỏe.
- ..................

## Direction / Định hướng

- Web phát triển trước.
- Mobile App phát triển sau.
- Có khả năng mở rộng thành sản phẩm thương mại.
- Có thể dùng làm nền tảng cho dự án Full Stack khác.

## Requirement Rule / Quy tắc yêu cầu

Mỗi yêu cầu mới phải ghi rõ:

- Mục tiêu.
- Người dùng liên quan.
- Luồng chính.
- Luồng ngoại lệ.
- Dữ liệu cần lưu.
- API cần có.
- Giao diện cần có.
- Kiểm thử bắt buộc.
- Tài liệu cần cập nhật.
