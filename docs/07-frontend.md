# Frontend / Giao diện Web

## Stack / Công nghệ

- React.
- Vite.
- TypeScript.
- Tailwind CSS.

## Structure Rule / Quy tắc cấu trúc

Frontend phải tách theo feature hoặc module rõ ràng. Component dùng chung đặt trong vùng shared khi bắt đầu triển khai.

## State Rule / Quy tắc trạng thái

Chỉ thêm state management library khi có nhu cầu thực tế và có quyết định trong tài liệu module hoặc architecture.

## UI Rule / Quy tắc UI

- Giao diện tiếng Việt.
- Code naming tiếng Anh.
- Component phải có trạng thái loading, empty và error khi phù hợp.
- Form phải có validation phía client và vẫn phải validate lại ở backend.
