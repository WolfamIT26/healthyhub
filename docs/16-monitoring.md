# Monitoring / Giám sát

## Scope / Phạm vi

Monitoring theo dõi sức khỏe hệ thống, lỗi, hiệu năng, bảo mật và chi phí AI.

## Metrics / Chỉ số

- API latency.
- Error rate.
- Database slow query.
- Auth failure rate.
- Payment failure rate.
- AI request count.
- AI token usage.
- AI provider error rate.

## Logging / Ghi log

Log phải đủ để debug nhưng không được chứa secret, password, token hoặc dữ liệu nhạy cảm không cần thiết.
