# Apps / Ứng dụng

Thư mục `apps` chứa các ứng dụng triển khai chính.

## Applications / Ứng dụng

- `web`: ứng dụng React + Vite + TypeScript + Tailwind CSS.
- `api`: backend Node.js + TypeScript, dùng NestJS hoặc Express.js khi bắt đầu triển khai.
- `mobile`: mobile app chuẩn bị cho tương lai, chưa triển khai code.

## Rule / Quy tắc

Giai đoạn hiện tại chưa triển khai code nghiệp vụ. Chỉ giữ cấu trúc để AI Agent phát triển sau khi có requirement rõ ràng.
