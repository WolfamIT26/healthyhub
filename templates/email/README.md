# Email Templates / Mẫu email

## Purpose / Mục tiêu

Thư mục này chứa template email dạng Markdown để backend hoặc notification gateway triển khai sau.

## Rule / Quy tắc

- Không hard-code dữ liệu người dùng thật.
- Placeholder dùng dạng `{{variable_name}}`.
- Nội dung UI/email cho khách hàng dùng tiếng Việt.
