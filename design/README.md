# Design System / Hệ thống thiết kế

## Purpose / Mục tiêu

Thư mục này quản lý asset, prototype, screenshot và tài nguyên thiết kế của HealthyHub.

Tài liệu Design System chuẩn nằm tại [docs/design-system](../docs/design-system/README.md). Khi cần đọc nguyên tắc, token hoặc component guideline, ưu tiên đọc `docs/design-system` trước.

## Folders / Thư mục

- `components`: tài liệu component UI.
- `colors`: bảng màu.
- `typography`: font và cấp chữ.
- `spacing`: khoảng cách layout.
- `icons`: icon guideline.
- `screenshots`: ảnh chụp màn hình thiết kế hoặc kiểm thử.

## Rule / Quy tắc

Giao diện người dùng dùng tiếng Việt. `design/` không phải nơi viết code frontend; thư mục này chỉ giữ tài nguyên thiết kế, prototype và ảnh kiểm tra sau này.
