# Database / Cơ sở dữ liệu

Thư mục này chứa migration, seed, schema mẫu và diagram database.

## Folders / Thư mục

- `migrations`: migration theo thứ tự thời gian.
- `seeds`: dữ liệu mẫu cho local development.
- `schemas`: script schema khởi tạo nếu cần.
- `diagrams`: ERD hoặc tài liệu trực quan.

## Rule / Quy tắc

Mọi thay đổi database phải cập nhật `docs/04-database.md` và `Database.md` của module liên quan.

## ERD / Sơ đồ ERD

ERD được chuẩn bị trong `database/diagrams` với các định dạng Draw.io, PNG và PDF.
