# Package Manager / Quản lý package

## Package Manager / Package manager

Framework dùng npm workspaces ở giai đoạn hiện tại.

## Rule / Quy tắc

- Không commit `node_modules`.
- Không cài dependency nếu chưa bắt đầu triển khai app thật.
- Dependency mới phải có lý do và cập nhật tài liệu liên quan.
