# Storage / Lưu trữ file

## Purpose / Mục tiêu

Thư mục này chuẩn bị cấu trúc quản lý file cho development hoặc local storage.

## Folders / Thư mục

- `uploads`: file người dùng upload.
- `products`: ảnh sản phẩm.
- `certificates`: giấy chứng nhận hoặc tài liệu kiểm định.
- `temporary`: file tạm.
- `backup`: bản sao local của file cần sao lưu.

## Rule / Quy tắc

Không commit file upload thật, giấy tờ thật hoặc dữ liệu cá nhân. Chỉ commit guideline và placeholder.
