# Error Catalog / Danh mục lỗi API

## Purpose / Mục tiêu

Error Catalog mapping chuẩn lỗi Data Contract sang lỗi API cho từng nhóm domain. Mã lỗi dùng pattern `CATEGORY.DOMAIN.REASON`.

## Common Error Mapping / Mapping lỗi dùng chung

| HTTP Status / Mã HTTP | Category / Nhóm | Example Code / Mã ví dụ | Usage / Cách dùng |
| --- | --- | --- | --- |
| 400 | VALIDATION | `VALIDATION.COMMON.BAD_REQUEST` | Request sai format tổng thể. |
| 401 | AUTH | `AUTH.AUTHENTICATION.UNAUTHORIZED` | Chưa đăng nhập hoặc thiếu token. |
| 401 | AUTH | `AUTH.AUTHENTICATION.TOKEN_INVALID` | Token sai, hết hạn hoặc bị thu hồi. |
| 403 | PERMISSION | `PERMISSION.COMMON.FORBIDDEN` | Không đủ quyền. |
| 404 | NOT_FOUND | `NOT_FOUND.COMMON.RESOURCE_NOT_FOUND` | Resource không tồn tại hoặc bị ẩn theo quyền. |
| 409 | CONFLICT | `CONFLICT.COMMON.VERSION_CONFLICT` | Xung đột version hoặc trạng thái. |
| 422 | VALIDATION | `VALIDATION.COMMON.INVALID_INPUT` | Field validation thất bại. |
| 429 | RATE_LIMIT | `RATE_LIMIT.COMMON.TOO_MANY_REQUESTS` | Vượt giới hạn gọi API. |
| 500 | SYSTEM | `SYSTEM.COMMON.INTERNAL_ERROR` | Lỗi hệ thống không lộ chi tiết. |
| 502 | INTEGRATION | `INTEGRATION.COMMON.PROVIDER_ERROR` | Provider ngoài lỗi. |
| 503 | SYSTEM | `SYSTEM.COMMON.SERVICE_UNAVAILABLE` | Service tạm không sẵn sàng. |

## Error Response Rule / Quy tắc phản hồi lỗi

- Mọi lỗi trả envelope theo [API Envelope](../data-contracts/api-envelope.md).
- Validation lỗi field theo [Validation Response](../data-contracts/validation-response.md).
- Lỗi không được lộ SQL, stack trace, provider secret, storage key hoặc prompt raw.
- `requestId`, `traceId` và `supportCode` phải đủ để support tra log sau này.
