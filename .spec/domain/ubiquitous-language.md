# Ubiquitous Language / Ngôn ngữ chung

## Purpose / Mục tiêu

Ubiquitous Language chuẩn hóa thuật ngữ dùng trong Business Blueprint, Feature Specifications, Domain Model, Database Design và API Design sau này.

| --- | --- |

## Naming Rule / Quy tắc dùng thuật ngữ

- Tài liệu tiếng Việt có thể giải thích thuật ngữ bằng tiếng Việt, nhưng tên domain/entity/value object nên dùng tiếng Anh nhất quán.
- Database/API prompt sau này phải dùng cùng thuật ngữ, không tự đổi nghĩa.
