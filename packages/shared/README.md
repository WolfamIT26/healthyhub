# Shared Package / Gói dùng chung

## Purpose / Mục tiêu

Khu vực này dành cho type, constant hoặc utility dùng chung khi dự án bắt đầu có code.

## Current Status / Trạng thái hiện tại

Package cũ này được giữ lại để không phá cấu trúc Phase 2.

Từ Prompt 14, shared foundation chính nằm ở:

- `packages/shared-types`: type contract dùng chung.
- `packages/shared-utils`: helper dùng chung.
- `packages/shared-config`: constant cấu hình dùng chung.

Các package trên chỉ chứa nền tảng kỹ thuật, không chứa code nghiệp vụ.
