# Assets System / Hệ thống tài nguyên

## Purpose / Mục tiêu

Thư mục này quản lý tài nguyên dùng chung cho thương hiệu, thiết kế và sản phẩm.

## Folders / Thư mục

- `logos`: logo thương hiệu.
- `icons`: icon dùng chung.
- `images`: hình ảnh chung.
- `fonts`: font.
- `mockups`: mockup thiết kế.
- `illustrations`: minh họa.
- `banners`: banner.

## Mapping / Ánh xạ

`apps/web/src/assets` là tài nguyên runtime của web app. `assets` ở root là kho tài nguyên dự án.
