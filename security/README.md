# Security / Bảo mật

Thư mục này chứa chính sách, checklist và báo cáo bảo mật.

## Rule / Quy tắc

Mọi tính năng liên quan auth, payment, dữ liệu cá nhân hoặc AI phải có kiểm tra bảo mật trước khi release.

## Security Topics / Chủ đề bảo mật

- Authentication.
- Authorization.
- JWT.
- Permission.
- OWASP guideline.
- Data privacy.

Tài liệu chi tiết nằm trong `security/policies` và checklist nằm trong `security/checklists`.
