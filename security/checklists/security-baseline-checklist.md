# Security Baseline Checklist / Checklist bảo mật nền tảng

- [ ] Authentication flow được mô tả.
- [ ] Authorization và permission được mô tả.
- [ ] JWT secret lấy từ environment.
- [ ] Input validation được áp dụng ở backend.
- [ ] SQL Injection được phòng chống bằng binding hoặc abstraction an toàn.
- [ ] XSS được phòng chống khi hiển thị dữ liệu người dùng.
- [ ] CSRF strategy được xác định nếu dùng cookie.
- [ ] Rate limit được áp dụng cho API rủi ro cao.
- [ ] Log không chứa secret.
- [ ] Data privacy được đánh giá.
- [ ] OWASP Top 10 đã được xem xét.
