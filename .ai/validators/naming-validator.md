# Naming Validator / Kiểm tra đặt tên

## Checks / Tiêu chí kiểm tra

- File name tiếng Anh.
- Folder name tiếng Anh.
- Tài liệu framework dùng tên rõ nghĩa.
- Module dùng domain name rõ.
- Không trộn tiếng Việt trong file/folder.

## Failure Signals / Dấu hiệu lỗi

- Tên file quá chung như `new.md`, `update.md`, `note.md`.
- Tên không phản ánh nội dung.
- Nhiều file khác tên nhưng cùng vai trò.
