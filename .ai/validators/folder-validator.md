# Folder Validator / Kiểm tra thư mục

## Checks / Tiêu chí kiểm tra

- Folder dùng tiếng Anh.
- Folder mới có vai trò rõ trong architecture hoặc workflow.
- Không tạo folder trùng ý nghĩa với folder hiện có.
- Nếu thêm folder cấp root hoặc `.ai`, cập nhật folder structure docs.
- Folder dùng `kebab-case` khi có nhiều từ.

## Failure Signals / Dấu hiệu lỗi

- Folder đặt tên tiếng Việt.
- Folder chỉ dùng để chứa file tạm.
- Folder mới không được nhắc trong README hoặc index liên quan.
