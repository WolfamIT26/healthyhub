# Markdown Validator / Kiểm tra Markdown

## Checks / Tiêu chí kiểm tra

- Có heading chính song ngữ.
- Nội dung chính bằng tiếng Việt.
- Heading ngắn, rõ vai trò.
- Link tương đối đúng ngữ cảnh.
- Không có phần trống.
- Bảng dùng khi cần so sánh hoặc mapping.

## Failure Signals / Dấu hiệu lỗi

- Có heading nhưng không có nội dung.
- Nội dung lặp lại y nguyên tài liệu khác.
- Tài liệu không nêu mục tiêu hoặc quy tắc áp dụng.
