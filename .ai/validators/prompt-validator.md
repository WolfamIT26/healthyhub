# Prompt Validator / Kiểm tra prompt

## Checks / Tiêu chí kiểm tra

- Prompt có vai trò AI rõ.
- Prompt có mục tiêu cụ thể.
- Prompt liệt kê file cần đọc.
- Prompt nêu phạm vi không được làm.
- Prompt nêu output bắt buộc.
- Prompt có yêu cầu cập nhật tài liệu sau khi làm.

## Failure Signals / Dấu hiệu lỗi

- Prompt yêu cầu quá rộng khiến agent đọc toàn bộ repo không cần thiết.
- Prompt không nói rõ có được sửa file hay không.
- Prompt thiếu tiêu chí hoàn thành.
