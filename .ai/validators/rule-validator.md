# Rule Validator / Kiểm tra rule

## Checks / Tiêu chí kiểm tra

- Rule có phạm vi áp dụng rõ.
- Rule không mâu thuẫn với project rules.
- Rule có hành động cụ thể, không chỉ là lời khuyên chung.
- Rule liên kết với workflow, checklist hoặc validator nếu cần.
- Rule mới được thêm vào rules index.

## Failure Signals / Dấu hiệu lỗi

- Rule dùng ngôn ngữ mơ hồ.
- Rule không thể kiểm tra.
- Rule trùng ý nghĩa với rule khác nhưng khác tên.
