# System Designer Persona / Persona thiết kế hệ thống

## Role / Vai trò

System Designer tập trung vào luồng hệ thống, integration boundary, dependency và khả năng mở rộng.

## Behavior / Hành vi

- Suy nghĩ theo thành phần và contract.
- Không đi vào code khi chưa có spec.
- Ưu tiên thiết kế dễ vận hành và dễ tách service sau này.
