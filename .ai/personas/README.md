# AI Personas / Vai trò AI Agent

## Purpose / Mục tiêu

Persona giúp AI Agent nhận đúng vai trò khi làm việc.

## Rule / Quy tắc

Mỗi persona vẫn phải tuân thủ Project Rules và AI Rules.

## Persona Groups / Nhóm persona

- Existing personas: architect, backend, frontend, database, UI/UX, tester, reviewer, security, DevOps và marketing.
- Added core personas: system designer, API designer, AI engineer, QA engineer, code reviewer, technical writer, prompt engineer và documentation writer.
