# Testing Workflow / Quy trình kiểm thử

## When to Use / Khi sử dụng

Dùng khi nhiệm vụ yêu cầu thiết kế test, review test hoặc chạy kiểm tra phù hợp với phạm vi.

## Required Reading / Tài liệu cần đọc

- `docs/foundation/testing/README.md`
- Rule testing trong `.ai/rules`
- Module hoặc feature spec liên quan nếu có.
- Security và performance guideline nếu luồng có rủi ro.

## Steps / Các bước

1. Xác định mức rủi ro của thay đổi.
2. Chọn loại test phù hợp: unit, integration, e2e, manual, security hoặc performance.
3. Thiết kế checklist hoặc test plan.
4. Chạy kiểm tra nếu có lệnh an toàn và phù hợp.
5. Ghi rõ test đã chạy và test chưa chạy.

## Output Rule / Quy tắc đầu ra

Không tuyên bố hoàn tất kiểm thử nếu chưa chạy hoặc chưa mô tả rõ test coverage.
