# Documentation Workflow / Quy trình tài liệu

## When to Use / Khi sử dụng

Dùng khi nhiệm vụ yêu cầu tạo, cập nhật, chuẩn hóa hoặc tổng hợp tài liệu.

## Required Reading / Tài liệu cần đọc

- `docs/00-project-rules.md`
- `docs/foundation/development/documentation-workflow.md`
- `.ai/rules/03-documentation-rules.md`
- `.ai/rules/17-markdown-rules.md` nếu có.

## Steps / Các bước

1. Xác định cấp tài liệu: foundation, framework, module, feature, AI hoặc summary.
2. Kiểm tra tên file và vị trí.
3. Viết nội dung tiếng Việt, heading song ngữ.
4. Tránh lặp lại nội dung đã có; dùng liên kết khi cần.
5. Cập nhật index, status, report, checklist, changelog và work summary.

## Output Rule / Quy tắc đầu ra

Tài liệu phải có mục tiêu, phạm vi, quy tắc áp dụng và phần liên quan khi cần.
