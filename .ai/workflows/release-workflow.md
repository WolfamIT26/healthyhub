# Release Workflow / Quy trình release

## When to Use / Khi sử dụng

Dùng khi nhiệm vụ yêu cầu chuẩn bị release, release note, checklist hoặc version history.

## Required Reading / Tài liệu cần đọc

- `docs/foundation/standards/release-strategy.md`
- `docs/foundation/standards/versioning-strategy.md`
- `docs/foundation/deployment/deployment-strategy.md`
- `.ai/skills/10-release-management-skill.md`

## Steps / Các bước

1. Xác định version hoặc milestone.
2. Kiểm tra thay đổi đã được review và test.
3. Ghi release note và checklist.
4. Kiểm tra backup, rollback và monitoring.
5. Cập nhật changelog và work summary.

## Output Rule / Quy tắc đầu ra

Release không được coi là sẵn sàng nếu thiếu rollback plan cho thay đổi có rủi ro dữ liệu hoặc bảo mật.
