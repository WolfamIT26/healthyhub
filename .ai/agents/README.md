# AI Agents / Khung AI Agent

## Purpose / Mục tiêu

Thư mục `agents` định nghĩa các agent theo vai trò. Mỗi agent có phạm vi, tài liệu cần đọc, đầu ra được phép và giới hạn không được vượt qua.

## Common Rule / Quy tắc chung

Agent không tự ý chuyển vai trò nếu prompt chưa yêu cầu. Nếu nhiệm vụ cần nhiều vai trò, agent chính phải ghi rõ vai trò phụ được dùng.
