# AI Knowledge Framework / Khung tri thức AI

## Purpose / Mục tiêu

Thư mục `.ai/knowledge` lưu tri thức framework dành cho AI Agent. Không lưu dữ liệu nghiệp vụ sản phẩm, khách hàng, đơn hàng hoặc database thật.

## Knowledge Files / File tri thức

- [Framework Knowledge Map / Bản đồ tri thức framework](framework-knowledge-map.md)
- [Architecture Knowledge / Tri thức kiến trúc](architecture-knowledge.md)
- [Documentation Knowledge / Tri thức tài liệu](documentation-knowledge.md)
- [Security Knowledge / Tri thức bảo mật](security-knowledge.md)
- [AI Workflow Knowledge / Tri thức workflow AI](ai-workflow-knowledge.md)

## Boundary Rule / Quy tắc ranh giới

Nếu tri thức là dữ liệu sản phẩm, dinh dưỡng, chính sách bán hàng hoặc marketing thật, lưu trong thư mục `knowledge` ở root, không lưu trong `.ai/knowledge`.
