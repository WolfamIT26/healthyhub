# Documentation Checklist / Checklist tài liệu

## Checklist / Danh sách kiểm tra

- [ ] Tài liệu có mục tiêu rõ.
- [ ] Heading song ngữ English + Vietnamese.
- [ ] Nội dung chính bằng tiếng Việt.
- [ ] File name tiếng Anh.
- [ ] Không có phần trống hoặc nội dung chung chung.
- [ ] Có liên kết tài liệu liên quan khi cần.
- [ ] Index hoặc README liên quan đã cập nhật.
- [ ] Work summary đã tạo trong `docs/work-summaries`.
