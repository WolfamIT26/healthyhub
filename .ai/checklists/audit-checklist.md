# Audit Checklist / Checklist audit

## Checklist / Danh sách kiểm tra

- [ ] Đã lập danh sách tiêu chí audit.
- [ ] Đã đọc cấu trúc file thực tế.
- [ ] Đã phân loại phần đã có, còn thiếu, mapping và đề xuất.
- [ ] Không sửa file nếu prompt chỉ yêu cầu audit.
- [ ] Rủi ro được nêu theo tác động.
- [ ] Đề xuất tương lai không bị nhầm với phần đã triển khai.
