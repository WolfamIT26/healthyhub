# Release Checklist / Checklist release

## Checklist / Danh sách kiểm tra

- [ ] Version hoặc milestone đã rõ.
- [ ] ChangeLog đã cập nhật.
- [ ] Release note đã có.
- [ ] Test result đạt yêu cầu.
- [ ] Backup và rollback plan đã chuẩn bị nếu có dữ liệu.
- [ ] Monitoring và alert liên quan đã xác định.
- [ ] Known issues được ghi rõ nếu còn.
