# Testing Checklist / Checklist kiểm thử

## Checklist / Danh sách kiểm tra

- [ ] Đã xác định mức rủi ro của thay đổi.
- [ ] Đã chọn loại test phù hợp.
- [ ] Đã ghi rõ test đã chạy.
- [ ] Đã ghi rõ test chưa chạy và lý do.
- [ ] Có kiểm tra security nếu thay đổi liên quan dữ liệu, auth hoặc quyền.
- [ ] Có kiểm tra performance nếu thay đổi liên quan query, API hoặc tải lớn.
