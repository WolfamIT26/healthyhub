# AI Agent Operating System / Hệ điều hành làm việc cho AI Agent

## Goal / Mục tiêu

Đảm bảo mọi AI Agent làm việc theo cùng quy trình, cùng ngôn ngữ và cùng chuẩn tài liệu.

## Steps / Các bước

1. Đọc project rules.
2. Đọc folder structure.
3. Đọc context.
4. Xác định module liên quan.
5. Lập scope.
6. Thực hiện task.
7. Kiểm tra.
8. Cập nhật tài liệu bắt buộc.
9. Ghi report.
