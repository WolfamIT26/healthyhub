# Database Design Skill / Kỹ năng thiết kế database

## Goal / Mục tiêu

Thiết kế schema MySQL rõ ràng, tối ưu và có khả năng mở rộng.

## Output / Đầu ra

- Table list.
- Column list.
- Relationship.
- Index.
- Migration plan.
- Seed plan nếu cần.

## Rule / Quy tắc

Mọi thay đổi database phải cập nhật `Database.md` của module và `docs/04-database.md` nếu là thay đổi chuẩn hệ thống.
