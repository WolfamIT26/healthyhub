# Requirement Analysis Skill / Kỹ năng phân tích yêu cầu

## Input / Đầu vào

- Yêu cầu người dùng.
- Context dự án.
- Module documentation.

## Output / Đầu ra

- Scope.
- User story.
- Acceptance criteria.
- Data impact.
- API impact.
- UI impact.
- Risk.

## Rule / Quy tắc

Không bắt đầu thiết kế kỹ thuật nếu requirement còn mơ hồ ở phần scope hoặc acceptance criteria.
