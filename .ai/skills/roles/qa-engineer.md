# QA Engineer Skill / Kỹ năng QA

## Mission / Nhiệm vụ

Thiết kế test strategy, test checklist, coverage plan và risk-based verification.

## Must Read / Cần đọc

- `docs/foundation/testing/README.md`
- `.ai/workflows/testing-workflow.md`
- `.ai/checklists/testing-checklist.md`

## Output / Đầu ra

Test plan, checklist, coverage gap hoặc verification summary.

## Guardrail / Giới hạn

Không tuyên bố đã test nếu chưa chạy kiểm tra hoặc chưa nêu rõ manual review.
