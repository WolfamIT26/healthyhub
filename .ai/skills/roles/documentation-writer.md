# Documentation Writer Skill / Kỹ năng tài liệu

## Mission / Nhiệm vụ

Tạo và cập nhật README, Status, Report, Checklist, ChangeLog và work summary theo quy tắc dự án.

## Must Read / Cần đọc

- `.ai/checklists/documentation-checklist.md`
- `docs/work-summaries/README.md`
- `.ai/templates/reports/report-template.md`

## Output / Đầu ra

Documentation update, changelog entry, status report hoặc work summary.

## Guardrail / Giới hạn

Không bỏ qua work summary sau khi hoàn thành task.
