# Role Skills / Kỹ năng theo vai trò

## Purpose / Mục tiêu

Thư mục `roles` định nghĩa skill chuẩn theo vai trò AI. Các skill này bổ sung cho bộ skill workflow hiện có trong `.ai/skills`.

## Usage Rule / Quy tắc sử dụng

AI Agent chọn role skill theo vai trò chính của nhiệm vụ. Nếu nhiệm vụ cần nhiều vai trò, role phụ chỉ hỗ trợ kiểm tra chéo và không được làm vượt phạm vi prompt.
