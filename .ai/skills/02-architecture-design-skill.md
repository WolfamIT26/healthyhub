# Architecture Design Skill / Kỹ năng thiết kế kiến trúc

## Goal / Mục tiêu

Thiết kế module, layer, dependency và gateway theo Modular Monolith.

## Output / Đầu ra

- Module boundary.
- Layer mapping.
- Dependency map.
- Gateway contract nếu có.
- Microservice readiness note.
- Architecture decision.
