# AI Skill System / Hệ thống kỹ năng AI

## Purpose / Mục tiêu

Skill mô tả cách AI Agent thực hiện một loại công việc cụ thể trong framework.

## Usage / Cách dùng

AI Agent chọn skill phù hợp với nhiệm vụ, đọc rule liên quan, thực hiện theo workflow và cập nhật tài liệu sau khi hoàn tất.

## Skill Groups / Nhóm skill

- Workflow skills: các file đánh số từ `00` đến `10` trong thư mục này.
- Role skills: [roles/README.md](roles/README.md) cho Software Architect, System Designer, Database Designer, API Designer, Frontend Developer, Backend Developer, UI/UX Designer, AI Engineer, Security Engineer, DevOps Engineer, QA Engineer, Code Reviewer, Technical Writer, Prompt Engineer và Documentation Writer.
