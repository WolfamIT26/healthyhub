# Documentation Update Skill / Kỹ năng cập nhật tài liệu

## Goal / Mục tiêu

Đảm bảo thay đổi được phản ánh đầy đủ trong tài liệu module và tài liệu hệ thống.

## Required Updates / Cập nhật bắt buộc

- `Status.md`.
- `Report.md`.
- `Checklist.md`.
- `ChangeLog.md`.
- File chuyên biệt nếu có thay đổi Database, API, Frontend, Backend, Testing hoặc Architecture.
