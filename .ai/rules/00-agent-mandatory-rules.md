# Agent Mandatory Rules / Quy tắc bắt buộc cho AI Agent

## Before Work / Trước khi làm

1. Đọc `docs/00-project-rules.md`.
2. Đọc `docs/01-folder-structure.md`.
3. Đọc `.ai/context/README.md`.
4. Đọc module context liên quan trong `docs/modules` hoặc `.ai/templates/module`.

## During Work / Trong khi làm

- Không viết code nghiệp vụ nếu nhiệm vụ chỉ yêu cầu thiết kế framework.
- Không thêm framework mới nếu chưa có quyết định.
- Giữ phạm vi thay đổi nhỏ và đúng mục tiêu.
- Ghi assumption rõ ràng khi thiếu thông tin.

## After Work / Sau khi làm

Bắt buộc cập nhật:

- `Status.md`.
- `Report.md`.
- `Checklist.md`.
- `ChangeLog.md`.
- Một file tổng hợp mới trong `docs/work-summaries`.

Nếu có thay đổi:

- Database: cập nhật `Database.md`.
- API: cập nhật `API.md`.
- Architecture: cập nhật tài liệu Architecture.
