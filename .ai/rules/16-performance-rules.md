# Performance Rules / Quy tắc hiệu năng

## Rule / Quy tắc

- Không tối ưu mù khi chưa có dữ liệu đo.
- Danh sách lớn phải có pagination.
- Query quan trọng phải xem xét index.
- API không trả dữ liệu thừa.
- AI request phải có timeout, fallback và context nhỏ nhất đủ dùng.

## AI Agent Check / Kiểm tra cho AI Agent

Khi thiết kế feature sau này, nêu rõ performance impact nếu có query, upload, image, AI hoặc external gateway.
