# Prompt Rules / Quy tắc prompt

## Rule / Quy tắc

- Prompt dùng tiếng Việt.
- Prompt phải nêu vai trò, mục tiêu, file cần đọc, phạm vi được làm và phạm vi không được làm.
- Prompt phải nêu output bắt buộc.
- Prompt review phải nói rõ không sửa file nếu chỉ audit.
- Prompt tạo mới phải yêu cầu cập nhật status, report, checklist, changelog và work summary.
- Prompt không được yêu cầu gửi secret hoặc dữ liệu nhạy cảm cho AI provider.

## AI Agent Check / Kiểm tra cho AI Agent

Khi tạo prompt template, dùng `.ai/validators/prompt-validator.md` để tự kiểm tra.
