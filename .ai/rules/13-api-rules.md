# API Rules / Quy tắc API

## Rule / Quy tắc

- API naming dùng tiếng Anh.
- API design phải có request, response, error và permission rõ.
- API phải cập nhật tài liệu API hoặc OpenAPI khi triển khai thật.
- Không tạo endpoint nếu chưa có requirement và spec.
- Gateway API phải có timeout, error mapping và logging rule.

## Prompt 04 Boundary / Ranh giới Prompt 04

Prompt 04 chỉ tạo framework hỗ trợ API design, không tạo API nghiệp vụ.
