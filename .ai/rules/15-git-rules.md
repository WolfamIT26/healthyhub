# Git Rules / Quy tắc Git

## Rule / Quy tắc

- Không commit secret.
- Commit message dùng format rõ ràng theo commit convention.
- Không gom nhiều thay đổi không liên quan vào một commit.
- Không xóa hoặc revert thay đổi của người khác khi chưa được yêu cầu.
- Pull Request phải nêu phạm vi, test và tài liệu cập nhật.

## AI Agent Check / Kiểm tra cho AI Agent

Khi báo cáo thay đổi, nêu rõ file đã thêm, file đã cập nhật và kiểm tra đã chạy.
