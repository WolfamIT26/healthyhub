# Folder Rules / Quy tắc thư mục

## Rule / Quy tắc

- Folder dùng tiếng Anh.
- Folder mới phải có vai trò rõ trong source, docs, AI, config, security, testing, deployment hoặc operations.
- Không tạo folder trùng ý nghĩa với folder hiện có.
- Folder nhiều từ dùng `kebab-case`.
- Khi thêm folder quan trọng, cập nhật README hoặc folder structure liên quan.

## AI Agent Check / Kiểm tra cho AI Agent

Trước khi tạo folder, chạy kiểm tra danh sách file/thư mục hiện tại và tìm mapping tương đương.
