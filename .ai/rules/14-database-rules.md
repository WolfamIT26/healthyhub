# Database Rules / Quy tắc database

## Rule / Quy tắc

- Database object dùng tiếng Anh.
- Database design phải dựa trên feature spec.
- Mọi thay đổi schema phải cập nhật Database.md và migration note.
- Query quan trọng phải xem xét index, pagination và performance.
- Không tạo schema hoặc seed nếu chưa có yêu cầu rõ.

## Prompt 04 Boundary / Ranh giới Prompt 04

Prompt 04 không tạo database schema, migration hoặc seed.
