# Markdown Rules / Quy tắc Markdown

## Rule / Quy tắc

- Nội dung Markdown dùng tiếng Việt.
- Heading dùng song ngữ English + Vietnamese.
- File name dùng tiếng Anh.
- Tài liệu phải có mục tiêu rõ.
- Không để phần trống hoặc câu chung chung không kiểm chứng được.
- Dùng link tương đối đến tài liệu liên quan khi cần.

## AI Agent Check / Kiểm tra cho AI Agent

Sau khi tạo tài liệu, kiểm tra lại heading, link, nội dung trùng lặp và phần cần cập nhật index.
