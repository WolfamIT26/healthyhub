# Language and Naming Rules / Quy tắc ngôn ngữ và đặt tên

## Folder / Thư mục

Folder dùng tiếng Anh.

## File Name / Tên file

File name dùng tiếng Anh. Tài liệu nền tảng dùng numbering để dễ đọc theo thứ tự.

## Markdown / Nội dung Markdown

Markdown content dùng tiếng Việt. Heading dùng song ngữ English + Vietnamese.

## Code / Code

Code naming dùng tiếng Anh. Comment dùng tiếng Việt khi comment thực sự cần thiết.

## Database and API / Database và API

Database table, column và API endpoint dùng tiếng Anh.

## UI / Giao diện

Giao diện người dùng dùng tiếng Việt.
