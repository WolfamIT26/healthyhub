# Security Rules / Quy tắc bảo mật

## Secret / Thông tin bí mật

Không hard-code password, token, API key hoặc secret vào source code, tài liệu hoặc log.

## Input / Dữ liệu đầu vào

Mọi input từ client, file, AI prompt hoặc external integration phải được validate.

## API / Giao tiếp API

API nhạy cảm phải có authentication, authorization, rate limit và logging phù hợp.

## Data Privacy / Quyền riêng tư dữ liệu

Không đưa dữ liệu cá nhân vào prompt AI nếu không có mục đích rõ và biện pháp bảo vệ.
