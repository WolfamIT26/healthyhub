# Coding Rules / Quy tắc code

## Rule / Quy tắc

- Chỉ viết code khi prompt cho phép rõ ràng.
- Code naming dùng tiếng Anh.
- Comment trong code dùng tiếng Việt khi thật sự cần giải thích.
- Không hard-code secret, credential hoặc URL production.
- Không đưa business logic vào sai layer.
- Không thêm framework mới khi chưa có ADR.

## Prompt 04 Boundary / Ranh giới Prompt 04

Prompt 04 không cho phép tạo frontend, backend, database hoặc code nghiệp vụ.
