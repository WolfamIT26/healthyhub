# Documentation Rules / Quy tắc tài liệu

## Module Files / File module bắt buộc

- `Database.md`.

- `Frontend.md`.

## Update Rule / Quy tắc cập nhật

Không hoàn thành task nếu chưa cập nhật tài liệu bị ảnh hưởng. Nếu không có thay đổi tài liệu, phải ghi rõ lý do trong report.
