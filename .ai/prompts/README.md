# Prompt Template System / Hệ thống prompt template

## Purpose / Mục tiêu

Prompt template giúp AI Agent làm việc nhất quán theo từng loại nhiệm vụ.

## Rule / Quy tắc

Prompt dùng tiếng Việt. Khi dùng prompt, phải thay các placeholder như `{module_name}`, `{task_scope}` và `{expected_output}` bằng thông tin cụ thể.

Prompt standard chi tiết nằm tại `14-prompt-standard.md`.

## Framework Prompt Library / Thư viện prompt framework

Prompt framework nằm tại [framework/README.md](framework/README.md), dùng cho generate, review, refactor, audit, testing, documentation, release, validation, context pack và ADR. Thư mục này không chứa prompt nghiệp vụ.
