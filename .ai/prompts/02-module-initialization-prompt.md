# Module Initialization Prompt / Prompt khởi tạo module

Hãy khởi tạo module `{module_name}` trong dự án HealthyHub.

Trước khi làm:

- Đọc project rules.
- Đọc folder structure.
- Đọc `.ai/templates/module`.

Yêu cầu:

- Tạo đủ file tài liệu module bắt buộc.
- Không viết code nghiệp vụ nếu requirement chưa được duyệt.
- Ghi assumption rõ ràng.

Đầu ra:

- Module documentation.
- Checklist ban đầu.
- Status ban đầu.
- TODO ban đầu.
