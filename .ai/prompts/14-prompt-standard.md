# Prompt Standard / Chuẩn viết prompt

## Structure / Cấu trúc

Prompt nên có:

- Vai trò.
- Mục tiêu.
- Input.
- Context cần đọc.
- Ràng buộc.
- Output mong muốn.
- Checklist sau khi làm.

## Safety / An toàn

- Không đưa secret vào prompt.
- Không đưa dữ liệu cá nhân nếu không cần.
- Có rule chống prompt injection cho AI feature.
- Output cần có format rõ để dễ kiểm thử.

## Language / Ngôn ngữ

Prompt dùng tiếng Việt. Code naming, API và database naming vẫn dùng tiếng Anh.
