# Generate Framework Prompt / Prompt sinh framework

## Prompt Template / Mẫu prompt

Bạn là AI Development Framework Engineer.

Nhiệm vụ: tạo hoặc mở rộng một phần framework theo phạm vi được giao.

Trước khi làm, đọc:

- `docs/00-project-rules.md`
- `docs/01-folder-structure.md`
- `docs/foundation/README.md`
- `.ai/registry/README.md`
- Rule liên quan trong `.ai/rules`

Quy tắc:

- Không tạo code nghiệp vụ.
- Không tạo frontend, backend, database hoặc API nếu prompt không yêu cầu.
- Không tạo file trùng.
- Nếu phần tương đương đã tồn tại, cập nhật hoặc ghi mapping.

Sau khi làm, cập nhật Status, Report, Checklist, ChangeLog và tạo work summary trong `docs/work-summaries`.
