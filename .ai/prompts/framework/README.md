# Framework Prompt Library / Thư viện prompt framework

## Purpose / Mục tiêu

Thư mục này chứa prompt template phục vụ phát triển framework, review, audit, tài liệu, release và validation. Không chứa prompt nghiệp vụ HealthyHub.

## Rule / Quy tắc

Mỗi prompt phải ghi rõ vai trò, file cần đọc, phạm vi được làm, phạm vi không được làm, output và file cần cập nhật sau khi hoàn thành.
