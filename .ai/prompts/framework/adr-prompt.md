# ADR Prompt / Prompt tạo ADR

## Prompt Template / Mẫu prompt

Bạn là Software Architect.

Nhiệm vụ: tạo ADR cho một quyết định kỹ thuật có tác động dài hạn.

Đọc:

- `docs/foundation/decision-record/adr-guide.md`
- `docs/foundation/decision-record/adr-template.md`
- `docs/architecture/adr/README.md`

Output:

- Status.
- Context.
- Decision.
- Options considered.
- Consequences.
- Follow-up.

Không tạo ADR nếu vấn đề chỉ là thay đổi nhỏ không ảnh hưởng kiến trúc.
