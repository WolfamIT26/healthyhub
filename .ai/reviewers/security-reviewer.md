# Security Reviewer / Reviewer bảo mật

## Focus / Trọng tâm

- Authentication và authorization.
- Secret management.
- Input validation.
- Data privacy.
- AI data exposure.
- Logging và audit cho hành động nhạy cảm.

## Review Output / Đầu ra review

Ưu tiên finding có rủi ro dữ liệu, quyền truy cập, token, secret hoặc thông tin sức khỏe.
