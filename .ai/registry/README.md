# AI Registry / Sổ đăng ký AI Core

## Purpose / Mục tiêu

Registry quản lý danh mục skills, prompts, templates, context packs, agents và rules để AI Agent tìm đúng tài nguyên thay vì dò toàn bộ repository.

## Registry Files / File registry

- [Skills Registry / Đăng ký skill](skills-registry.md)
- [Prompts Registry / Đăng ký prompt](prompts-registry.md)
- [Templates Registry / Đăng ký template](templates-registry.md)
- [Context Packs Registry / Đăng ký context pack](context-packs-registry.md)
- [Agents Registry / Đăng ký agent](agents-registry.md)
- [Rules Registry / Đăng ký rule](rules-registry.md)

## Update Rule / Quy tắc cập nhật

Khi thêm skill, prompt, template, context pack, agent hoặc rule, phải cập nhật registry tương ứng.
