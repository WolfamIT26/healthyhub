# AI Templates / Template cho AI Agent

## Folders / Thư mục

- `module`: template tài liệu bắt buộc cho mỗi module.
- `workflow`: template theo quy trình phát triển.
- `checklists`: checklist dùng khi phát triển và release.
- `reports`: template báo cáo, trạng thái, quyết định và changelog.
- `framework`: template mở rộng AI Development Core như skill, rule, prompt, context pack, workflow, validator, reviewer, agent, registry và memory.
