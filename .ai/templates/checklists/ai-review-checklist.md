# AI Review Checklist / Checklist review AI

- [ ] AI feature có use case rõ.
- [ ] Input được validate.
- [ ] Prompt không chứa secret.
- [ ] Có kiểm soát prompt injection.
- [ ] Output có format rõ.
- [ ] Có fallback khi provider lỗi.
- [ ] Có logging rule an toàn.
- [ ] Có privacy note.
- [ ] Có test case cho input nguy hiểm.
- [ ] Có ghi chú chi phí hoặc giới hạn token.
