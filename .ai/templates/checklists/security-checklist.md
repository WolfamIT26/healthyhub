# Security Checklist / Checklist bảo mật

- [ ] Không hard-code secret.
- [ ] Input được validate.
- [ ] API nhạy cảm có authentication.
- [ ] API nhạy cảm có authorization.
- [ ] Có rate limit khi cần.
- [ ] Chống SQL Injection.
- [ ] Chống XSS.
- [ ] Có CSRF strategy nếu dùng cookie.
- [ ] Log không chứa token, password hoặc secret.
- [ ] Dữ liệu cá nhân được xử lý đúng mục đích.
