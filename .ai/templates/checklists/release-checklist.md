- [ ] Requirement hoàn tất.
- [ ] Test pass.
- [ ] Security checklist hoàn tất.
- [ ] Performance risk đã đánh giá.

- [ ] Rollback plan đã có.
- [ ] Documentation đã cập nhật.
- [ ] Root `CHANGELOG.md` đã cập nhật.
- [ ] Module `ChangeLog.md` đã cập nhật.
