# AI Feature Checklist / Checklist tính năng AI

- [ ] Use case rõ ràng.
- [ ] Input được validate.
- [ ] Output có format mong muốn.
- [ ] Prompt không chứa secret.
- [ ] Có kiểm soát prompt injection.
- [ ] Có fallback khi provider lỗi.
- [ ] Có giới hạn token hoặc chi phí.
- [ ] Có test case cho input bất thường.
- [ ] Có privacy note.
- [ ] Có logging rule an toàn.
