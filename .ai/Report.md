# AI Core Report / Báo cáo AI Core

## Summary / Tóm tắt

Prompt 04 đã hoàn thiện AI Development Core trong `.ai`. Hệ thống mới giúp AI Agent làm việc có vai trò rõ, workflow rõ, rule rõ, checklist kiểm soát, validator/reviewer để tự kiểm tra và registry để tìm tài nguyên nhanh.

## Added / Đã thêm

- `.ai/workflows`: workflow generate, review, refactor, audit, testing, documentation và release.
- `.ai/checklists`: checklist vận hành theo workflow.
- `.ai/validators`: validator cho folder, Markdown, naming, prompt, documentation và rule.
- `.ai/reviewers`: reviewer profile cho architecture, security, documentation, prompt và AI.
- `.ai/registry`: registry quản lý skills, prompts, templates, context packs, agents và rules.
- `.ai/knowledge`: knowledge framework cho AI Agent, không chứa dữ liệu nghiệp vụ.
- `.ai/agents`: agent framework theo vai trò.
- `.ai/skills/roles`: role skills chuẩn.
- `.ai/prompts/framework`: prompt template framework.
- `.ai/context-packs/core`: context pack core để tối ưu token.
- `.ai/templates/framework`: template mở rộng AI Core.
- Memory history mới: prompt, module và change history.
