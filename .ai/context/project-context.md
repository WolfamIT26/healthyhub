# Project Context / Ngữ cảnh dự án

## Project / Dự án

Tên dự án: HealthyHub.

HealthyHub là nền tảng bán các sản phẩm healthy như sữa hạt, sữa chua, đồ ăn dinh dưỡng và thực phẩm sức khỏe.

## Direction / Định hướng

- Web first.
- Mobile later.
- Commercial-ready.
- Reusable Full Stack AI Development Framework.

## Current Phase / Giai đoạn hiện tại

Giai đoạn khởi tạo framework. Không triển khai code nghiệp vụ.
