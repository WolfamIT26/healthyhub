# Context Management / Quản lý ngữ cảnh

## Purpose / Mục tiêu

Quản lý cách AI Agent đọc và sử dụng ngữ cảnh để tránh thiếu thông tin hoặc xử lý sai scope.

## Reading Rule / Quy tắc đọc

1. Đọc project rules.
2. Đọc folder structure.
3. Đọc context tổng quan.
4. Đọc module hoặc domain liên quan.
5. Chỉ đọc file mở rộng khi task thật sự cần.

## Update Rule / Quy tắc cập nhật

Khi thay đổi domain, stack, architecture, gateway hoặc AI capability, phải cập nhật file context tương ứng.
