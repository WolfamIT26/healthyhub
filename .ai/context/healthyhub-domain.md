# HealthyHub Domain / Miền nghiệp vụ HealthyHub

## Product Groups / Nhóm sản phẩm

- Nut milk / Sữa hạt.
- Yogurt / Sữa chua.
- Nutrition food / Đồ ăn dinh dưỡng.
- Health products / Thực phẩm sức khỏe.

## Expected User Groups / Nhóm người dùng dự kiến

- Customer / Khách hàng.
- Admin / Quản trị viên.
- Staff / Nhân viên vận hành.
- Marketing user / Nhân sự marketing.

## Domain Rule / Quy tắc nghiệp vụ

Mọi module nghiệp vụ phải mô tả rõ người dùng, dữ liệu, API, UI, backend logic, security và test case trước khi triển khai code.
