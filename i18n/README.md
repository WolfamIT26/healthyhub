# Internationalization / Đa ngôn ngữ

## Purpose / Mục tiêu

Chuẩn bị cấu trúc i18n cho tiếng Việt và tiếng Anh. Chưa triển khai thư viện i18n.

## Folders / Thư mục

- `vi`: nội dung tiếng Việt.
- `en`: nội dung tiếng Anh.

## Rule / Quy tắc

Giao diện mặc định của HealthyHub dùng tiếng Việt. Tiếng Anh là ngôn ngữ chuẩn bị mở rộng.
