# Disaster Recovery / Khôi phục thảm họa

## Purpose / Mục tiêu

Chuẩn bị quy trình khôi phục khi hệ thống gặp sự cố lớn.

## Checklist / Checklist

- [ ] Xác định sự cố.
- [ ] Chọn bản backup phù hợp.
- [ ] Restore database.
- [ ] Restore file storage.
- [ ] Kiểm tra API, web, auth, order và payment.
- [ ] Ghi report sau sự cố.
