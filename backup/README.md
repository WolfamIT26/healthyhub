# Backup / Sao lưu

## Purpose / Mục tiêu

Thư mục này chuẩn bị cấu trúc sao lưu database, file upload và tài liệu quan trọng.

## Folders / Thư mục

- `database`: bản sao lưu database.
- `files`: bản sao lưu file upload.
- `documents`: bản sao lưu tài liệu quan trọng.

## Rule / Quy tắc

Không commit file backup thật nếu chứa dữ liệu người dùng, secret hoặc dữ liệu production.
